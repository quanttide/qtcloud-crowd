# 众包云使用指南

> 面向：**众包管理方**（运营量潮众包市场的人）
> 定位：管理市场的任务、执行方与结算——不是发单/接单的交易界面

## 三个核心动作

### 1. 审核任务

- 需求方提交任务 → 审核是否可发单
- **验收准则不清晰 → 打回补全**（说不清验收 = 不发单）
- 归档分类（招聘考核 / 业务任务 / 运营任务 …）
- 跟踪状态：待认领 → 进行中 → 待验收 → 已完成/已关闭
- 交付后按验收准则裁决（通过 / 打回修改）

### 2. 管理执行方

- 准入认证（渠道 / 代理 / 实训基地成员）
- 记录交付质量（执行记录沉淀）

### 3. 结算

- 验收通过后按量潮标准结算
- 结算记录留痕（可追溯）

## 一句话补充

- **信用（远期）**：执行记录沉淀为信用，高信用优先接单
