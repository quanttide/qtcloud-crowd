# 众包云使用指南

> 面向：**众包管理方**（运营量潮众包市场的人）
> 定位：管理众包市场的任务、执行方、结算与信用——不是发单/接单的交易界面

## 管理方职责

```
任务管理 → 执行方管理 → 结算管理 → 信用管理 → 市场状态
```

## 任务管理

- **任务审核**：需求方提交的任务（业务/类别/内容清单/验收准则）——审核是否可发单
  - 验收准则不清晰 → 打回补全（说不清验收 = 不发单）
  - 类别归档：招聘考核 / 业务任务 / 运营任务 …
- **任务状态跟踪**：待认领 → 进行中 → 待验收 → 已完成 / 已关闭
- **验收裁决**：执行方交付后，按验收准则裁决（通过/打回修改）

## 执行方管理

- **准入审核**：注册申请 → 审核认证（渠道/代理/实训基地成员）
- **执行方档案**：认证等级、接单记录、交付质量
- **异常处理**：逾期/违约执行方的标记与处置

## 结算管理

- **结算标准**：按量潮标准结算（任务类别 × 交付质量）
- **结算单**：生成/确认结算（验收通过后）
- **结算记录**：台账留痕（可追溯）

## 信用管理

- **信用记录**：执行率/验收通过率/准时率沉淀
- **信用应用**：影响执行方后续接单优先级（高信用优先）

## 市场状态（数据视图）

- 任务池：在发/进行中/待验收/已完成数量
- 执行方：认证数/活跃数/信用分布
- 结算：待结算/已结算金额

## 原则

1. **管理方视角**：本工具管理市场（审核/裁决/结算/信用）——不代替需求方发单、不代替执行方做任务
2. **验收准则兜底**：审核任务是管理方的第一道关
3. **标准交易**：标准任务、标准交付、标准验收——管理方保证标准执行
