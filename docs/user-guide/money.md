# 财：结算管理

> 众包云三视角之「财」——验收通过后的结算

## 想象中的样子

```
结算单列表
├── 待结算：验收通过的任务 → 生成结算单 → 确认金额
├── 结算标准：任务类别 × 交付质量 → 自动算金额
└── 结算记录：已结算台账（可追溯、可对账）
```

- 验收通过自动进入待结算队列
- 金额按标准自动计算，人工只确认
- 台账与财务对账（可追溯）

## 最精简的样子

```
一个动作：结算记录
└── 验收通过 → 记一笔（任务 + 金额 + 时间）
```

- 不做的：自动算金额/结算单/对账（远期）
- 先做的：**验收通过后记一笔账**（钱从哪来、付给谁、付了多少——有记录就够了）

## 精简理由

结算的本质是"验收通过 → 记录付款"。金额计算和台账对账是钱多了以后的事——先保证每笔结算有记录。
